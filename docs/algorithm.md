# 算法演进与关键问题

## 0. 系统闭环

![前四问系统总体框图](images/system-block-diagram.png)

信号源一方面直接进入示波器 X 轴，另一方面经衰减偏置后送入 STM32；AD9833 输出经 OPA690 放大并分路，一路进入示波器 Y 轴，另一路经相同结构的衰减偏置网络反馈到 STM32。控制器由此获得 X、Y 两路同步采样数据，持续修正 DDS 的频率字和相位字。

核心数据流为：

```text
双ADC同步采样
      ↓
启动FFT测频 + 过零插值精化
      ↓
短帧正弦最小二乘拟合X/Y相位
      ↓
相位关系计算（1:1或2:1）
      ↓
快速相位环 + 慢速频率环
      ↓
更新AD9833频率字、相位字与幅度档位
      ↑________________________反馈
```

## 1. 为什么不是“测频后直接设置AD9833”

函数发生器和AD9833使用独立时钟。即使两者都显示100 kHz，真实频率仍可能相差零点几赫兹，导致相位持续旋转。示波器上的直线会逐渐张开成椭圆，圆和“∞”形也会转动。

因此系统必须同时解决：

- 瞬时相位差：决定图形当前角度和形状。
- 残余频率差：决定图形是否持续旋转。

## 2. 测量算法

启动时使用8192点FFT搜索输入频率，对数据去直流并加Hann窗，再通过谱峰相邻三点的对数域二次插值细化频率。

FFT频率分辨率仍不足以单独完成稳定闭环，因此加入带迟滞的多周期上升沿过零插值。FFT负责频谱搜索和有效性判断，过零法负责输出连续、稳定的频率估计。

获得基础频率后，用1024点短帧对X/Y进行正弦最小二乘拟合。该方法不要求窗口包含整数周期，可直接求出正弦、余弦系数，再计算幅值和相位。

## 3. 双环控制

快速相位环直接调整AD9833的12位相位寄存器。捕获阶段允许较大步进，接近锁定后降低步进并加入死区。

慢速频率环在观察窗口内累计相位变化，根据：

```text
Δf = Δφ / (360 × Δt)
```

估算真实频差并微调AD9833频率字，使相位停止持续旋转。

离散相位采样可能出现混叠和假锁定，因此还直接测量X/Y过零频率。大频差时使用 `fy-fx` 或 `fy-2fx` 粗调，小频差时切换到更安静的相位斜率精调。

## 4. 三种图形的控制变量

- 对角线：控制 `φY-φX=0°`
- 圆：控制 `φY-φX=90°`
- “∞”形：控制 `fY=2fX`，并令 `φY-2φX=0°`

第三问不能使用普通的 `φY-φX`，因为两路频率不同，该差值天然随时间变化；`φY-2φX` 才是与时间原点无关的对称性相位。

## 5. 稳定性处理

- 启动连续测量3帧并取中值，拒绝单次异常值。
- 每隔约1 s进行完整FFT复查，支持输入频率改变后自动重捕获。
- 连续多个窗口同时满足频率和相位阈值才进入锁定。
- 锁定后保留低增益频率微调，而不是完全冻结DDS频率字。
- 连续超出释放阈值后退出锁定，避免永久卡在错误状态。
- 对采样时钟比例误差和模拟链路固定相位差进行实测标定。

## 6. 典型实测性能

测试条件为100 kHz、4 Vpp正弦输入，STM32F407双ADC采样率约1.02 MSPS，X/Y反馈均经过结构一致的衰减和1.65 V偏置网络。

- 启动测频、DDS初始化和双环捕获完成时间约1 s。
- 进入`lock=1, hold=1`后，连续日志中的闭环相位残差保持在±0.07°以内。
- 典型残余频差约为数毫赫兹量级。
- 系统会将DDS指令频率调至略偏离标称值的位置，以补偿函数发生器、MCU和DDS独立时钟源的实际偏差。
- 幅度经硬件实测标定，amp=35/70/105/141分别对应约1/2/3/4 Vpp。

这里的±0.07°是控制器在反馈采样点计算得到的稳态残差。示波器观察点还会受到运放、阻容网络和走线传播延迟影响，因此同频模式额外加入了1 kHz为0°、100 kHz为2.5°的一次线性补偿。
