# 算法演进与关键问题

## 1. 为什么不是“测频后直接设置AD9833”

函数发生器和AD9833使用独立时钟。即使两者都显示100 kHz，真实频率仍可能相差零点几赫兹，导致相位持续旋转。示波器上的直线会逐渐张开成椭圆，圆和“∞”形也会转动。

因此系统必须同时解决：

- 瞬时相位差：决定图形当前角度和形状。
- 残余频率差：决定图形是否持续旋转。

## 2. 测量算法

启动时使用8192点FFT搜索输入频率，对数据去直流并加Hann窗，再通过谱峰相邻三点的对数域二次插值细化频率。

FFT频率分辨率仍不足以单独完成稳定闭环，因此加入带迟滞的多周期上升沿过零插值。FFT负责频谱搜索和有效性判断，过零法负责输出连续、稳定的频率估计。

获得基础频率后，用1024点短帧对X/Y进行正弦最小二乘拟合。该方法不要求窗口包含整数周期，可直接求出正弦、余弦系数，再计算幅值和相位。

## 3. 双环控制

快速相位环直接调整AD9833的12位相位寄存器。捕获阶段允许较大步进，接近锁定后降低步进并加入死区。

慢速频率环在观察窗口内累计相位变化，根据：

```text
Δf = Δφ / (360 × Δt)
```

估算真实频差并微调AD9833频率字，使相位停止持续旋转。

离散相位采样可能出现混叠和假锁定，因此还直接测量X/Y过零频率。大频差时使用 `fy-fx` 或 `fy-2fx` 粗调，小频差时切换到更安静的相位斜率精调。

## 4. 三种图形的控制变量

- 对角线：控制 `φY-φX=0°`
- 圆：控制 `φY-φX=90°`
- “∞”形：控制 `fY=2fX`，并令 `φY-2φX=0°`

第三问不能使用普通的 `φY-φX`，因为两路频率不同，该差值天然随时间变化；`φY-2φX` 才是与时间原点无关的对称性相位。

## 5. 稳定性处理

- 启动连续测量3帧并取中值，拒绝单次异常值。
- 每隔约1 s进行完整FFT复查，支持输入频率改变后自动重捕获。
- 连续多个窗口同时满足频率和相位阈值才进入锁定。
- 锁定后保留低增益频率微调，而不是完全冻结DDS频率字。
- 连续超出释放阈值后退出锁定，避免永久卡在错误状态。
- 对采样时钟比例误差和模拟链路固定相位差进行实测标定。
